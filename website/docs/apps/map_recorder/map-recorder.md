# Map Recorder Guide

## Overview

The Map Recorder application enables users to record and manage field maps for the Amiga.

## Features

- Real-time map recording
- Lost GPS 
You will not be able to Record a route or reoeat if if you have lost GPS.

![Screenshot from 2025-06-10 16-18-35](https://github.com/user-attachments/assets/59764db5-09be-46d0-a361-40b11b07c5db)

The robot will also come to an E-stop when you loose GPS. A pop up message will inform you that you have lost GPS and manual intervention will be required to resume operations once you have GPS
