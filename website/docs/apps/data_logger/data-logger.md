# Data Logger Guide

The Data Logger application provides comprehensive data collection and logging capabilities.

## Features

### Profile Management

   Create Profile - "+" button in profile header
   Select Profile - Dropdown menu showing all profiles
   Save Profile - "Save" button (appears when changes made)
   Delete Profile - Available through profile management

### Topic Selection

   Select Topics - Button that expands topic selection panel
   Toggle Topic - Individual toggle switches to enable or disable each data topic
   Back - Returns to default view from topic selection

### Camera Controls

   Camera Settings - Settings icon opens configuration panel
   Apply Settings - Confirms camera parameter changes
   Cancel - Discards camera setting changes
   Auto Exposure - Toggle switch
   Auto Focus - Toggle switch
   Manual Controls - Sliders for exposure time, ISO, lens position

### Data Annotation

   Annotate - Button to add timestamped notes to a data log
   Submit Annotation - Saves annotation text
   Cancel Annotation - Closes annotation panel

### Metadata Management

   Expand Metadata - Shows full metadata editor
   New Metadata - "New" button to add custom fields
   Create Field - Confirms new metadata entry
   Cancel Creation - "x" button cancels new field

### Application Controls

   Exit - Corner button to close application
   Save Changes - Global save for all unsaved modifications
   Warning Indicator - Red icon shows sections with unsaved changes

### Data Logging Operations

   Start Logging - Activates data recording
   Stop Logging - Terminates active recording
   Set Active Profile - Makes selected profile current
