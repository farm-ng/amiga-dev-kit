The file manger gives you file management capabilities for your recorded log files.
Topic streams from your selected data logger [**Profile**](/docs/apps/data_logger/data-logger#profile-management) will be included in these logs.
The first thing you will see is a **File list** that includes all of
your saved recordings. Press the **Refresh ↻** icon to reload the list
of saved event files.

### File Transfer
![Screenshot from 2025-06-25 13-29-10](https://github.com/user-attachments/assets/6b510580-62fe-4c55-9abc-433d48feae5a)
To transfer your files out
of the robot, connect a **USB Device** to the back of the brain
and click on the checkbox next to each file you wish to select.
Alternatively you can **Select All** files or **Deselect All** all files.
Press **Copy to USB** and your selected file(s) will be copied
to the USB device. Press the **Unmount USB** button to
safely eject the USB device.
Press the **Delete** button to permanently delete any selected file(s).
