  ## File Manager Guide

 ## File List View Functions

   **USB Device**
    USB dropdown selector for file operations
   **Refresh**
    ↻ (refresh icon) reloads the list of event files
   **Delete**
    This button deletes selected file(s) after confirmation
   **Copy to USB**
    Copies selected file(s) to the USB device
   **Unmount USB**
    Safely ejects the USB device
   **Select All**
    Selects all files
   **Deselect All**
    Deselects all files
   **Individual File Selection**
    Click on the checkbox next to each file you wish to select
